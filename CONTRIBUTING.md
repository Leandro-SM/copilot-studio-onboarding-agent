# Contribuindo

Obrigado pelo interesse em contribuir com este template **genérico** de onboarding com Copilot Studio! 🎉

Este é um projeto **educativo e agnóstico de organização**. Toda contribuição deve manter esse caráter neutro.

## 🧭 Princípios do projeto

- **Conteúdo genérico**: nada de dados, nomes, credenciais, endpoints ou processos de organizações específicas.
- **Segurança em primeiro lugar**: nunca inclua segredos, tokens ou senhas em exemplos, prompts ou arquivos.
- **Exemplos fictícios**: qualquer dado de exemplo deve ser claramente marcado como fictício.
- **Clareza**: prefira documentação objetiva e escaneável.

## 🌿 Fluxo de contribuição

1. Faça um **fork** do repositório.
2. Crie uma **branch** descritiva a partir da `main`:
   - `docs/...` para documentação
   - `chore/...` para manutenção
   - `fix/...` para correções
3. Faça suas alterações em commits pequenos e objetivos.
4. Abra um **Pull Request** para a `main` descrevendo o que mudou e por quê.

## ✅ Padrão de commits

Use mensagens no formato **Conventional Commits**:

```
tipo: descrição curta no imperativo
```

Tipos comuns: `docs`, `chore`, `fix`, `feat`, `refactor`.

Exemplos:
- `docs: adiciona seção de métricas`
- `chore: atualiza .gitignore`

## 🔍 Checklist antes de abrir o PR

- [ ] Conteúdo permanece **genérico** (sem referências internas)
- [ ] Nenhum segredo ou dado sensível incluído
- [ ] Exemplos marcados como fictícios
- [ ] Documentação revisada e clara
- [ ] Mensagens de commit no padrão

## 💬 Dúvidas e sugestões

Abra uma **issue** para propor melhorias ou discutir ideias antes de implementar mudanças maiores.

Toda contribuição é bem-vinda — de correções de digitação a novos guias! 🙌
